🔴 При ошибке:
  LaTeX-incompatible input and strict mode is set to 'warn': 
  Unicode text character "при" used in math mode [unicodeTextInMathMode]

сделать поиск по регулярному выражению в файле json в поле "formula":
  "formula"\s*:\s*"([^"]*при[^"]*)"   // допускаются пробелы вокруг двоеточия
  "formula":\s"([^"]*при[^"]*)"       // "formula": ""

Пояснение:
  "formula"\s*:\s*   "   ([^"]*в[^"]*)   "

  • \s - любой пробельный символ: пробел, табуляция, перевод строки и др.
  • [^"] любой символ, кроме двойной кавычки

  • "formula"\s*:\s* — фиксированная часть перед искомым значением
  • " — открывающая кавычка.
  • ([^"]*при[^"]*) — любая последовательность без кавычек, содержащая "при" в любом месте
  • " — закрывающая кавычка

Если нужно учесть экранированные кавычки внутри значения, можно заменить на более безопасную версию:
"formula"\s*:\s*"(?:(?:[^"\\]|\\.)*при(?:[^"\\]|\\.)*)"
